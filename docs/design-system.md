# Hi!Book Design System — V1.0 Foundation

The implementation follows the “Connected Social” visual direction.

## Brand

- Primary: Hi!Book teal #00B8A9
- Primary dark: #008F84
- Primary soft: #D9F7F4
- Accent: #FFC800
- Accent soft: #FFF4C2

Yellow is reserved for brand personality and emphasis. Functional states use semantic colors instead.

## Semantic colors

- Success: #16A34A
- Error: #DC2626
- Warning: #D97706
- Information: #2563EB

## Light surfaces

- Canvas: #F7F9FA
- Surface: #FFFFFF
- Secondary surface: #F1F5F5
- Primary text: #0F172A
- Secondary text: #64748B
- Muted text: #94A3B8
- Border: #E2E8F0
- Divider: #E8EEF0

## Dark surfaces

- Canvas: #0B1220
- Surface: #121C2B
- Secondary surface: #182536
- Primary text: #F8FAFC
- Secondary text: #CBD5E1
- Muted text: #94A3B8
- Border: #273548
- Divider: #223044

## Typography

Figtree is the primary testing candidate. The interface uses one type family across navigation, content, forms, and social UI.

## Radius

- sm: 4px
- md: 8px
- lg: 12px
- xl: 16px
- 2xl: 20px
- 3xl: 24px
- full: 999px

## Spacing

The first implementation uses a 4px base scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96.

## Design rule

Hi!Book should look like a place where people connect — not a place where books live.

Avoid literal book/page/paper/library metaphors in primary UI.
